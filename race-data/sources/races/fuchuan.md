# 跑山好时节，相约富川见

11月的岭南，刚褪去暑热，正是跑山的黄金时节。跑进600年明代古城，赴一场橙香满径的山野之约。

那2026富川（西岭药谷）古明城越野赛，绝对是你11月的必跑之选。赛事设有四个组别：

- 橙就巅峰50KM（L1级）：累计爬升2890m，关门15小时，拟ITRA积分3分。
- 橙风破浪35KM（M1级）：累计爬升2154m，关门11小时，拟 ITRA 积分2分。
- 橙胜追击18KM（S1级）：累计爬升325m，关门4小时，入门友好。
- 橙意满满 6KM：低难度欢乐跑，亲子、好友同行皆宜。

11月8日，富川古明城，等你来跑。
